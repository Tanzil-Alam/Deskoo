#Deskoo
This Desk pet has an oled. it shows eye animation. if anyone touch it, it becomes happy. and it also has a buzzer.
#How to use :
At first, you should print stl files. then open the Keychain-Robot.ino and also download Fluxgarage_RoboEyes.h Library. Then upload the ino to your esp32 and connect according ino file's connection.
